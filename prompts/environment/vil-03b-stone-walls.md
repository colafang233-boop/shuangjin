# VIL-03B 寒霜村石墙与边界模块

## 用途

生成可组合、可设置碰撞和遮挡的寒霜村石墙模块，替换当前游戏中单色矩形墙体，并建立村庄道路、院落和建筑边界。

## 生成规格

- 版式：严格 3×3，共 9 个独立模块
- 建议尺寸：2048×2048 正方形
- 背景：纯净浅灰或透明感中性背景
- 镜头：2.5D 斜俯视，水平约 45°，俯视约 35°–40°
- 光源：统一来自左上方
- 风格：中国北境古村、青灰石墙、手工砌筑、工笔线描
- 结构要求：墙脚、墙顶和朝向清楚，适合切图后组合
- 每格四周保留足够边距，模块不得越格

## 可直接复制的主提示词

生成一张严格 3×3 排列的中国古风仙侠 RPG 青灰石墙模块资产板，共九个完全独立、居中、互不接触的建筑边界模块。石墙属于寒冷北境的中国古村，由不规则青灰石块手工砌筑，墙顶有自然积雪，局部有薄冰、裂缝、苔痕和旧化，少量深色木构或旧铁件作为连接；固定 2.5D 斜俯视视角，水平约 45 度、俯视约 35 至 40 度，左上统一光源，轮廓精致、材质真实、具有工笔线描和早期国产单机 RPG 美术感。

九格按从左到右、从上到下依次为：

1. 水平直线短石墙模块；
2. 水平直线长石墙模块；
3. 竖向延伸石墙模块；
4. 左转外角石墙模块；
5. 右转外角石墙模块；
6. 内凹转角石墙模块；
7. 中段破损、可见缺口的石墙模块；
8. 带简洁中式木门框的墙体入口模块，门内为空；
9. 墙体末端、墙脚碎石与积雪收边模块。

所有模块应保持相同墙高、石块尺度、墙顶厚度、积雪量级和底部落点；墙顶与前立面层次明确，方便后续拆分遮挡层，不能画成西方城堡垛口。

## 强制禁止项

- 不要任何文字、牌匾、门联、数字、Logo、标签或水印
- 不要人物、动物、怪物、家具和完整建筑
- 不要 UI、地图截图、项目看板或说明文字
- 不要欧洲城堡、城垛、哥特尖拱、罗马石墙或日式庭院墙
- 不要过度规整的现代砖墙和水泥墙
- 不要卡通、像素风、塑料 3D 或高饱和手游风
- 不要模块相互粘连、裁断、比例不一或光线不一致

## 切图参数建议

```bash
python tools/slice-grid/slice_grid.py input.png output/ \
  --rows 3 --cols 3 \
  --trim-alpha --padding 8 \
  --canvas 640x640 \
  --anchor bottom-center \
  --prefix env_village_wall_stone_board01 \
  --contact-sheet preview.png
```

## 技术拆分要求

正式接入时，每个高墙模块至少拆为：

```text
base       墙脚、地面接触和碰撞参考
body       墙体主体
foreground 靠近镜头的墙顶或前缘遮挡层
snow       可选积雪覆盖层
shadow     可选接地阴影层
```

## 验收标准

- [ ] 九个模块墙高和石块尺度一致
- [ ] 直线、转角、破损、入口和末端均可辨认
- [ ] 模块组合后不出现明显透视断裂
- [ ] 有清楚墙脚，可生成合理碰撞区域
- [ ] 墙顶可用于角色遮挡或半透明处理
