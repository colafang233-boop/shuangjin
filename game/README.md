# 霜烬：沉冰地宫

这是《霜烬》第一章的无依赖 Canvas ARPG 灰盒垂直切片。

## 已实现

- 寒霜村、北境雪原、沉冰地宫与冰魄祭坛
- WASD、方向键和点击地面移动
- 点击敌人追击、空格普攻、右键闪避
- 冰刃、霜环、冰墙、寒霜护体四个技能
- 5类普通敌人、精英敌人与三阶段 Boss
- 经验升级、装备、药水和掉落
- NPC对话、主线、三条支线和临时队友
- 三道封印、普通结局与隐藏结局
- 浏览器本地自动存档
- `?test=1` 浏览器冒烟测试入口

## 本地运行

仓库根目录执行：

```bash
python3 -m http.server 8080
```

打开：

```text
http://localhost:8080/game/
```

浏览器冒烟测试：

```text
http://localhost:8080/game/?test=1
```

Node静态冒烟测试：

```bash
node game/tests/smoke.mjs
```

## 操作

- `WASD`、方向键或点击地面：移动
- 左键点击敌人：追击并攻击
- 右键：向鼠标方向闪避
- `空格`：普通攻击
- `1`：冰刃
- `2`：霜环
- `3`：冰墙
- `4`：寒霜护体
- `R`：生命药水
- `E`：交互；对话中可持续按 `E`、`Enter` 或空格继续
- `Q`：任务日志
- `I`：角色与背包

## 源码分片说明

当前执行环境不能直接向GitHub推送大文件，因此游戏逻辑以九个顺序源码分片保存在 `parts/`。`loader.js` 会按顺序读取、无损拼接并执行。它们不是编译产物，拼接结果就是完整源码。

后续在具备正常Git推送环境时，应通过工具脚本将分片合并为普通的 `game.js`，游戏行为不需要改变。

## 完整通关路径

1. 与韩伯交谈，开启主线。
2. 进入雪原并收集三枚冰魄碎片。
3. 可选：救陆沉，找到石小满并回村取得破冰剑。
4. 进入地宫，激活三道封印并消灭守卫波次。
5. 可选：收集三枚村民遗物。
6. 进入祭坛并击败冰魄将军玄戈。
7. 完成三条支线时，可选择净化玄戈并触发隐藏结局。
