# 第一波环境素材生产与接入计划

## 目标

用最少的正式环境素材，将灰盒寒霜村升级为可在线试玩的中国古风仙侠场景版本。

## 批次

| 批次 | 计划产出 | 最低可用数量 | 接入目标 |
|---|---:|---:|---|
| S00-09 材质语言 | 9格 | 1张风格板 | 后续环境资产共同参考 |
| VIL-01 木制杂物 | 16件 | 12件 | 村庄生活区、铁匠铺、入口区域 |
| VIL-02 陶器茶具 | 16件 | 12件 | 韩伯区域、火堆、桌面与房屋周边 |
| VIL-03A 地面块 | 16块 | 12块 | 石板路、雪地、冻土和过渡区域 |
| VIL-03B 石墙 | 9件 | 7件 | 村庄边界、院落、入口和迷宫可见墙体 |

## 接入顺序

1. 建立新的场景资产加载器，但保留灰盒回退绘制。
2. 先替换地面基础块，校准等距尺寸。
3. 再替换石墙，重新核对碰撞和遮挡。
4. 将木制杂物和陶器作为可配置装饰物接入。
5. 对交互物保留程序化高亮和 `[E]` 提示。
6. 执行冒烟测试和资产 Manifest 校验。
7. 部署 GitHub Pages 试玩版本。

## 玩家验收重点

- 道路与出口是否容易辨认；
- 墙体可见性是否足够，是否仍会误判碰撞；
- 道具比例是否和人物匹配；
- 同一屏幕内的木、石、雪、陶器是否像同一个世界；
- 复杂贴图是否影响战斗与交互提示可读性；
- 重复使用地块时是否出现明显拼贴感。

## 回退策略

每类正式素材都保留灰盒绘制回退：当贴图未加载、路径错误或尚未通过验收时，游戏继续使用原有程序化图形，避免素材生产阻塞可玩版本。
